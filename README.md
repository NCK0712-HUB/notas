# Sistema de notas (Maven + Swing)

Requisitos: JDK 21 y Maven.

    mvn clean package
    java -jar target/sistema-notas-1.0-SNAPSHOT.jar

En NetBeans: File > Open Project, y abre `interfaz.java` en la vista **Design** para editar el JFrame
(el diseño está en `src/main/java/sistema_notas/interfaz.form`).
